Cho hàm loss f(w) = (w − 3)², bắt đầu từ w₀ = 0, learning rate η = 0.1, quy tắc cập nhật w_mới = w − η · f′(w).

(a) Tính w₁.Đã làm
f′(w) = 2(w − 3) f′(0) = 2(0 − 3) = −6 w₁ = 0 − 0.1 · (−6) = 0.6
